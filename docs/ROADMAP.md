# 后续细化

当前版本是已接入真实论文快照的可运行框架，适合先确认信息组织与视觉方向。

## 内容与研究呈现

- 与作者确认官网短标题、作者信息、机构、论文发布链接、引用文本和联络方式。
- 将每个任务的样本数、评估协议、预算和 Gate/Quality 语义整理为专门的 protocol 元数据。当前保留原生 Quality 与实验来源，尚未新增 Gate 的交互视图。
- 加入 API-Bank 分层、监督数量与教师质量、验证集方法选择等诊断模块。
- 完善实验轨迹查看器；当前提供来源链接和诊断样例。
- 如需双语，将展示文案抽离到语言资源。

## 发布

- 创建 `fracture-atlas` 远端仓库，确认代码与实验数据的公开范围。
- 确定域名与静态托管，补充正式社交分享图片和站点元信息。
- 确认原研究仓库公开性，避免读者遇到无权限来源链接。
- 建立按审核后数据快照更新的发布流程；保留历史版本入口。

## 迭代边界

不添加跨指标的总排名；不将描述性基线直接用于差值；不将诊断回放计入正式成绩；不为未知成本补零。未来图表应继续保留原始协议和版本信息。
